# ADR-0001：Monorepo 与零依赖核心

- 状态：Accepted
- 日期：2026-07-27

## 决策

采用单仓库 npm workspaces Monorepo。M0 核心解析包只依赖 Node.js 22 标准库。

## 原因

- 多项目知识、规划器和执行 Adapter 需要共享模型；
- 单仓库方便保持文档、规则和测试同步；
- 零依赖核心降低供应链风险和离线环境安装成本；
- Node.js 22 已提供测试、加密和现代 ESM 能力。

## 后果

- M0 使用 JSON 而不是 YAML 作为运行时输入；
- 后续引入数据库、HTTP 服务或 YAML 时必须独立评审依赖；
- 核心模型暂以 JSDoc 和运行时校验保证契约。
