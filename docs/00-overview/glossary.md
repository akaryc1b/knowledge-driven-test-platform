# 术语与核心概念

| 术语 | 定义 |
|---|---|
| 知识规则 | 能够被机器读取和判定的一条边界定义 |
| 边界包 | 某个项目有效测试边界的结构化集合 |
| 领域能力包 | 可被多个项目绑定的通用领域规则集合 |
| 项目清单 | 描述项目身份、负责人、领域包和环境的入口文件 |
| 规则作用域 | GLOBAL、DOMAIN、PROJECT、ENVIRONMENT 或 RELEASE |
| 覆盖策略 | deny、strengthen 或 allow |
| 强制级别 | mandatory、default 或 optional |
| 知识快照 | 某次执行解析后的不可变有效规则集合 |
| 解析链 | 一条规则从低层到高层的继承和覆盖历史 |
| 孤儿测试 | 没有关联任何已发布知识的测试 |
| 覆盖缺口 | 已发布知识没有对应测试或证据 |
| 测试证据 | 执行结果、日志、报告和规则判定的持久记录 |
