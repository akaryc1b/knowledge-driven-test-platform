# 知识治理

## 状态机

```text
DRAFT → REVIEWING → PUBLISHED → DEPRECATED → ARCHIVED
```

正式测试只能消费 `PUBLISHED` 规则。

## 必备元数据

- 唯一知识 ID；
- 稳定边界键；
- 版本；
- 所属作用域；
- 负责人；
- 来源；
- 风险等级；
- 生效和失效时间；
- 关联 API、流程、权限、测试和事故。

## 审核原则

- 高风险规则必须双人审核；
- 公司 mandatory 规则必须由平台治理团队发布；
- 项目规则由项目产品、研发和质量负责人共同确认；
- AI 生成内容只能进入 DRAFT；
- 发布后修改必须创建新版本，不能覆盖历史版本。

## 知识健康指标

- 已发布规则数量；
- 无测试规则数量；
- 孤儿测试数量；
- 高风险规则覆盖率；
- 过期知识数量；
- 最近验证时间；
- 变更后回归完成率。
