# M0 — Knowledge Foundation

## 目标

完成一个可运行、可测试的多项目知识边界核心，不建设服务端和 UI。

## 安全切片

### M0-A 文档与模型

- 愿景、范围和术语；
- 多项目五层模型；
- 规则覆盖策略；
- 快照设计；
- ADR。

### M0-B Core Resolver

- 输入校验；
- 稳定排序；
- 冲突检测；
- 覆盖策略；
- 解析链。

### M0-C Snapshot Builder

- 规范化 JSON；
- SHA-256 摘要；
- 稳定快照 ID；
- 快照契约测试。

### M0-D Example and CLI

- 审批平台示例；
- 本地 CLI；
- CI 验证；
- 开发交接文档。

## 验收标准

- 所有测试通过；
- 相同规则不同输入顺序生成相同摘要；
- 全局强制规则无法被项目或发布层关闭；
- 同层冲突返回稳定错误码；
- 示例项目可生成完整快照；
- 仓库不包含外部运行时依赖。
