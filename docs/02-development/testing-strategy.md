# 测试策略

## M0 测试重点

- 规则结构校验；
- 五层优先级；
- mandatory 规则不能关闭；
- deny 规则不能修改；
- strengthen 覆盖必须显式声明；
- 同层冲突必须失败；
- 项目作用域必须匹配；
- 输入顺序变化不影响快照哈希。

## 测试类型

### 单元测试

验证单个规则解析和错误码。

### 契约测试

验证示例项目清单、规则文件和输出快照结构。

### 黄金快照测试

固定示例输入，校验生成的规则集合和摘要。避免直接把生成时间写入黄金文件。

### 后续集成测试

知识注册中心、测试规划器、k6 Adapter 和证据存储完成后再增加端到端验证。

## 质量门禁

```bash
npm test
npm run validate
npm run example:approval
```

任何合并都必须通过以上命令。
