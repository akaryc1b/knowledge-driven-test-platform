# 开发规范

## 基础环境

- Node.js 22；
- npm workspaces；
- ECMAScript Modules；
- 核心包优先使用 Node.js 标准库；
- 测试使用 `node:test`。

## 提交切片

每个开发切片必须：

1. 有明确边界和非目标；
2. 先更新设计或 ADR；
3. 提供单元测试；
4. 不混入无关重构；
5. 记录验证命令和结果。

## 编码要求

- 公共函数必须使用 JSDoc 描述输入和输出；
- 错误必须使用稳定错误码；
- 禁止依赖输入数组顺序形成业务结果；
- 禁止吞掉规则冲突；
- 禁止在核心解析中访问网络；
- 禁止把密钥、Token、真实业务数据提交到仓库。

## 兼容策略

M0 不承诺长期 API 稳定，但所有破坏性变更必须更新 ADR、示例和测试。
